# socket.io-server

A [Socket.IO](https://socket.io) v4 server for PHP, built on [Workerman](https://github.com/walkor/workerman).

> **Work in progress.** Not usable yet.

- Speaks Engine.IO v4 / Socket.IO protocol v5, for `socket.io-client` v3 and v4.
- PHP >= 8.1, Workerman 5.

For `socket.io-client` v1/v2, use [workerman/phpsocket.io](https://github.com/walkor/phpsocket.io).
